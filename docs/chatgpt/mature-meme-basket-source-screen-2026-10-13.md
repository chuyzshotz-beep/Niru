# Source feasibility: established Solana-meme basket (2026-10-13)

**Disposition:** the existing mature-meme-sector return modifier remains a low-priority, unapproved market-context hypothesis. This note narrows its data-source question; it does not establish predictive value, authorize capture, or change a strategy.

## Pyth path is not a no-cost API path

The local `scraper-predictability-plan.md` proposes a 15-minute median return across a fixed basket of established Solana-origin meme assets. Its listed Pyth Core feeds are plausible on-chain references, but the current Pyth pricing page says the $0 Free plan has no Pyth API access and is view-only; API access starts at the $500/month Starter plan. Hermes requests also require an API key after the August 2026 upgrade. Therefore do not build this candidate around Hermes or start a paid trial/subscription without separate owner approval. Pyth's price payload does provide a feed update time, and its documentation says consumers must distinguish newly generated from carried-forward prices; that timestamp alone would not solve the access/cost gate. [Pyth plans](https://www.pyth.network/pricing) [Hermes upgrade](https://docs.pyth.network/price-feeds/core/upgrade/preparing) [freshness field](https://docs.pyth.network/price-feeds/pro/payload-reference)

## Public-exchange alternative

Binance documents market-data-only REST and WebSocket URLs that require no API key. Its Spot `@trade` stream is real-time and includes both event time `E` and trade time `T` with price `p`. Its official notices confirm Solana-origin spot pairs BONK/USDT, WIF/USDT, and BOME/USDT. This provides a plausible low-cost point-in-time feed for a *small*, fixed mature-token basket without using Pyth or observing any wallet. [Binance public market-data endpoints](https://github.com/binance/binance-spot-api-docs/blob/master/faqs/market_data_only.md) [trade-stream schema](https://github.com/binance/binance-spot-api-docs/blob/master/web-socket-streams.md#trade-streams) [BONK listing](https://www.binance.com/en-AU/support/announcement/detail/1592b7a6ec9a408daf4b778f50ab1ca6), [WIF listing](https://www.binance.com/en/support/announcement/detail/90ad67fe5be7483ea058191bfde677e4), [BOME listing](https://www.binance.com/en-TR/support/announcement/detail/bca0f355cf004367b90d7e48fee3470c)

This alternative is not yet capture-ready. An approved outcome-blind pre-cohort check must confirm the exact live symbols, market-data endpoint availability, applicable data-use/retention terms, and complete trade-stream coverage. Freeze the eligible asset list before outcomes; do not silently add assets later. At each NIRU decision, require each included asset's last trade at or before the decision and prior endpoint to be fresh and fully received by the decision time. Record exchange event/trade timestamps and local receive time, preserve reconnect/sequence-gap diagnostics, and mark an incomplete basket unknown. Use one common quote convention and predeclare how USDT/USD basis is handled. A three-asset median is a narrow proxy, not a representative Solana-meme index.

The proposed feature remains a direction-unknown market-risk modifier, not standalone alpha. It must be tested against SOL/BTC returns, recent graduate peer flow, the focal pool, and existing market-time controls with the same target, time-forward split, market-block uncertainty, and market-context family correction already specified in `docs/plans/scraper-predictability-plan.md`. Drop it if the basket is incomplete, timing is ambiguous, stablecoin basis cannot be bounded, the feature is redundant after controls, or it fails the predeclared out-of-sample utility gate.
